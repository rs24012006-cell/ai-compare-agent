# 🚀 AI Compare Agent

## 📌 Overview
AI Compare Agent is an intelligent web application that compares a candidate’s **Resume** with a **Job Description** using AI.

It helps users:
- Identify skill gaps
- Get resume scores
- Practice AI-generated interview questions
- Build personalized learning roadmaps
- Download professional PDF reports

## ✨ Features

### 📊 Skill Analysis
- Compares Job Description vs Resume
- Shows Matched & Missing Skills
- Visual skill gap chart

### 🎯 Resume Score
- AI-based scoring system
- Gives percentage match

### 🎤 AI Interview Module
- Generates interview questions
- Evaluates user answers

### 📚 Learning Roadmap
- Suggests skills to learn
- Personalized improvement plan

### 📄 PDF Report Generator
- Professional downloadable report
- Includes score, skills, roadmap
